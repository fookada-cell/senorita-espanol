# Image style lock (owner decision, 2026-11-28)

Use this exact style line in EVERY image prompt from now on: scene images, spin-off scenes, character sheets, thumbnail art, channel banner. Copy it word for word; do not paraphrase or add extra style words (e.g. "1960s travel poster").

```
Style: Japanese retro travel-poster anime, warm detailed illustration, crisp linework, cel shading, soft golden light, rich warm colours, adult proportions, naturally sized eyes. Not 3D, not photorealistic, not pixel art. One single full frame, 16:9.
```

Always end each prompt with:
```
No text, letters, numbers, legible signs, logos, watermarks, grid, panels or split frames. Five fingers per hand.
```

(Thumbnail art and banner art: the same, but leave the title area empty; no "panels" wording changes.)
Character sheets: same style line, but layout "16:9, plain warm cream background" instead of a scene.
